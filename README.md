# WebCam on Demand (ESP32-CAM)

[English](README.en.md) | **Русский**

Автономная камера на ESP32-CAM / ESP32-S3-CAM с питанием от батареи. Почти всё время устройство находится в глубоком сне, периодически просыпается, делает фото и/или короткое видео на SD-карту и снова засыпает. По запросу (кнопка, таймер, команда MQTT) камера поднимается как Wi-Fi сервер со снимком и MJPEG-стримом, а после отключения клиента (или по таймауту простоя) засыпает.

## Возможности

- Глубокий сон, пробуждение по таймеру, PIR-датчику (ext1) и кнопке IO0 (ext0).
- Фото (JPEG) и видео (MJPEG AVI) на SD; действие для таймера и PIR настраивается: ничего / фото / видео / фото и видео.
- «Мёртвое время» PIR после срабатывания и защита от залипшего датчика (бэкофф 15 - 600 с).
- Серверный режим: страница управления, `/capture`, `/status`, `/sleep`, MJPEG-стрим на порту 81, mDNS `http://<device-id>.local`.
- Портал настроек (точка доступа `WebCam-XXXX`, captive DNS, сканирование сетей, привязка к BSSID).
- MQTT и автообнаружение Home Assistant; политика отправки: выкл / каждое событие / пачками / только в серверном режиме.
- Циклическая перезапись SD: при нехватке места удаляются самые старые данные.
- Синхронизация времени по SNTP; без установленного времени файлы на SD не пишутся.
- Расписание хранится в RTC-памяти и переживает глубокий сон.
- Конфигурация в NVS с версионированием и автоматической миграцией (v1, v2 -> v3).

## Поддерживаемые платы

| Плата | Чип | Flash | PSRAM | Окружение PlatformIO |
|---|---|---|---|---|
| AI-Thinker ESP32-CAM | ESP32 | 4 МБ | 4 МБ (quad) | `esp32cam_debug` / `esp32cam_release` |
| Freenove ESP32-S3-WROOM CAM | ESP32-S3 | 16 МБ | 8 МБ (octal) | `esp32s3cam_debug` / `esp32s3cam_release` |

Пины (кнопка, PIR, светодиод, камера, SD) заданы в `src/app_config.h` для обеих плат. На ESP32 PIR - GPIO13, на ESP32-S3 - GPIO14. SD работает в режиме SDMMC 1-bit.

## Режимы работы

| Причина пробуждения | Что происходит |
|---|---|
| Первое включение | Если Wi-Fi не настроен - портал; иначе серверный режим |
| Таймер (`timer_interval_s`) | Действие `timer_action`, затем сон |
| PIR | Действие `pir_action`, отправка события, «мёртвое время» |
| Кнопка IO0, короткое нажатие | Серверный режим |
| Кнопка IO0, удержание 3 с | Портал настроек (светодиод горит) |
| Периодически (`srv_period_s`) | Серверный режим, если включено |

## Сборка и прошивка

Требуется [PlatformIO](https://platformio.org/) (фреймворк ESP-IDF).

```bash
pio run -e esp32s3cam_release            # сборка
pio run -e esp32s3cam_release -t upload  # прошивка
pio device monitor                       # монитор порта
```

Для AI-Thinker используйте `esp32cam_release`. Если программатора нет, переведите плату в режим загрузки (IO0 на GND).

## Первая настройка

1. Включите питание: камера создаст открытую точку доступа `WebCam-XXXX` (XXXX - последние 4 символа `device_id`).
2. Подключитесь к ней, откройте `http://192.168.4.1` (откроется само как captive-портал).
3. Выберите сеть кнопкой сканирования, введите пароль, при необходимости MQTT и параметры съёмки, сохраните.
4. Устройство перезагрузится и перейдёт в обычный режим.

Повторно открыть портал: удерживайте IO0 3 секунды при пробуждении.

## Хранение на SD

```
/sdcard/YYYYMMDD/IMG_HHMMSS.jpg
/sdcard/YYYYMMDD/VID_HHMMSS.avi
/sdcard/log.txt  (ротация 256 КБ -> log.old)
```

При включённой перезапись (`sd_overwrite`) и нехватке места удаляются самые старые папки по датам. Порог записи - 20 МБ свободного места, очистка освобождает ещё 50 МБ запаса, для видео добавляется оценка размера записи. Старые файлы в корне (`IMG_*`, `VID_*`) удаляются первыми.

## MQTT

Префикс по умолчанию: `webcam/<device_id>`.

| Топик | Направление | Описание |
|---|---|---|
| `<prefix>/status` | устройство -> брокер | `awake` / `asleep` (LWT, retain) |
| `<prefix>/state` | устройство -> брокер | JSON: причина пробуждения, RSSI, IP, свободное место SD, интервал |
| `<prefix>/event` | устройство -> брокер | JSON событий из журнала |
| `<prefix>/motion` | устройство -> брокер | `ON` при срабатывании PIR |
| `<prefix>/snapshot` | устройство -> брокер | JPEG-снимок |
| `<prefix>/cmd/server_mode` | брокер -> устройство | `1` - перейти в серверный режим |
| `<prefix>/cmd/snapshot` | брокер -> устройство | `1` - сделать снимок |
| `<prefix>/cmd/set_interval` | брокер -> устройство | интервал таймера, с (10 - 604800) |

Команды выполняются при ближайшем пробуждении с сетевой сессией (камера спит между ними). Сущности Home Assistant создаются автоматически (`homeassistant/.../config`).

## Известные ограничения

- Команды MQTT доставляются не мгновенно, а при следующем пробуждении.
- Точка доступа портала открытая; пароль Wi-Fi передаётся по HTTP. Используйте портал в доверенной обстановке.
- Для стрима в высоком разрешении ограничением является Wi-Fi, а не PSRAM.
